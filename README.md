# The Parallel Universe Gazette

Type a "What if...?" and get the front page of a newspaper from that universe: headlines, stories, weather, sports, stocks, classifieds, a letter, a cartoon and drawn "photos", all generated by Claude and animated in the browser.

## Run it

```
npm install
cp .env.example .env    # then open .env and paste your own key
npm start
```

Open http://localhost:3000. On a phone, join the same Wi-Fi and open `http://<laptop-ip>:3000`.

## How to use it

1. **Pick a universe.** Type a "What if...?" in the cream box (for example *"What if cats ran the government?"*) and press **Enter Universe**, or tap one of the six sticker bubbles for a ready-made idea.
2. **Enjoy the trip.** The portal sucks you in and a warp tunnel plays for about 25–30 seconds while Claude writes every story and draws every picture.
3. **Read your newspaper.** It drops in and unfolds. Scroll down to read it all. Photos show "Developing photo..." for a few seconds before the drawing appears.
4. **Play with it.** Tap, hold and drag things on the page (see the table below). Pop-ups appear on their own about every 12 seconds.
5. **Go further.** Press **Fast-forward 10 years** for the same world a decade later, or **New universe** to start again.

| Do this | What happens |
|---|---|
| Move the mouse (or tilt your phone) | The scene tilts in 3D |
| Click the middle of the portal | Shockwave; the floating pages scatter and drift back |
| Drag a floating page, sticker, chip, headline or photo | It flings and springs back |
| Tap a photo | It flips to a secret behind-the-scenes joke |
| Double-tap a photo | Full-screen zoom (tap to close) |
| Hold a headline for half a second | Tabloid version (hold again to restore) |
| Swipe left/right, or ← → keys | Switch between editions (after a Fast-forward) |
| Press `N` or shake the phone | Random new universe |
| Esc | Close a pop-up or the zoom |
| Yellow 🔊 button, bottom right | Sound on/off (remembered) |

Each visitor gets **5 editions** in total (Fast-forward counts as one). After that, the app shows saved editions from the archive.

`http://localhost:3000/?demo=1` (or 2, 3) opens a saved edition instantly, with no API call.

## Features

**Generated by Claude**
- A full front page for any premise: masthead, banner headline, 3 stories (one quietly touching), weather, sports scoreboard, stock ticker, 3 classifieds, a letter to the editor, an editorial cartoon, chaos and believability scores, and 4 pop-ups.
- Five drawn "photos" (flat cartoon SVGs), each with a caption and a hidden behind-the-scenes joke.
- **Fast-forward 10 years:** a sequel edition that stays consistent with the world already invented.
- Claude Fable 5.2 writes the page (at low effort, for speed), Claude Haiku 5.5 draws the photos in parallel, and Claude Sonnet 5.5 is the backup writer.

**Landing page**
- A 3D portal of spinning glowing rings with a breathing core and orbiting sparkles.
- Floating newspaper pages and stickers at different depths, plus drifting star dust and ink drops in parallax layers.
- A bouncing title, a typewriter tagline, a "BREAKING: YOU ARE HERE" stamp, a chunky newspaper-style input and an ink-splat button.
- A one-second suck-in transition into the warp tunnel.

**The newspaper**
- Aged newsprint look: torn edges, stamps, polaroid photos with sepia and halftone effects, a handwritten letter.
- The paper drops in and unfolds panel by panel; title letters bounce in; the BREAKING stamp slams down with a screen shake.
- Scroll animations: headlines slide in, photos straighten, story text reveals line by line, scores and meters count up, the cartoon builds itself, and an ink-roller progress bar runs across the top.

**Pop-ups** (one at a time, each dismissible)
- A BREAKING banner with a siren, a fake ad whose close button dodges, a reader poll whose "No" button runs away, and a newsboy cameo.

**Sound**
- Generated effects (press clack, paper rustle, stamp thud, siren) with a mute button.

**Reliability and safety**
- One automatic retry, then a random saved edition, so a live demo never shows a blank screen.
- The API key stays on the server. Requests are validated and size-limited, Claude's output is escaped, drawings are sanitized, and security headers are set.
- Works on laptops and phones, and shows a calm version when the device asks for reduced motion.

## If the API fails

The app retries once, then prints a random saved edition from `public/data/`, so the demo keeps going. To save more editions while the server is running:

```
node save-edition.mjs 4 "What if trains ran on gossip?"
```

Then raise `FALLBACK_COUNT` in `public/js/app.js`.

## How it works

- `server.js`: Express. `POST /api/generate` returns the edition as JSON (text only); `POST /api/svg` draws one photo. The API key stays on the server. Model names are constants at the top of the file.
- Generation is split so the page appears after the text call (about 25 seconds) and the five drawings fade in over the next few seconds.
- `public/js/`: `app.js` (flow and state), `render.js` (JSON to DOM, SVG sanitizing), `motion.js` (GSAP, scroll, 3D tilt, warp), `popups.js`, `gestures.js`, `sound.js` (generated tones).
- `tools/`: dev-only scripts that drive a headless browser for checks. Not used by the app.

## Known limits

- Tilt and shake need a secure (https) page on phones, so they will not work over a plain local-network address.
- Fast-forward does not use the archive fallback; on failure you stay on the current edition.

## Security notes

- The API key lives only in `.env`, which is git-ignored. Copy `.env.example` to `.env` and add your own key. Never commit `.env`.
- The server sends a Content-Security-Policy, pins the GSAP CDN files with integrity hashes, limits request size, validates input, and limits each visitor to 5 editions in total (Fast-forward counts as one; resets when the server restarts; the host machine itself is exempt) and 50 drawings per minute.
- Everything Claude returns is escaped before it reaches the page, and drawings pass through an SVG sanitizer (`sanitizeSvg` in `public/js/render.js`). `tools/test-xss.js` feeds the renderer a hostile edition to check this.
- There is no login. Anyone who can reach the server can spend your API credits up to the rate limit, so run it on a network you trust and do not expose it to the internet as is.
